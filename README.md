# Cyberdeck Web

La partie Netrunner du launcher **Cyberdeck**, jouable dans un navigateur : profil, XP, NEURA, jeux et contacts.

Site : https://djoneb.github.io/cyberdeck-web/

- Reprendre sa partie : dans le launcher, *Paramètres → Sauvegarde → Exporter*, puis importer le fichier sur le site.
- Renvoyer sa partie au téléphone : *Sauvegarde → Télécharger*, puis dans le launcher *Restaurer une progression*.
- La progression reste dans le navigateur (stockage local). Rien n'est envoyé sur un serveur.
